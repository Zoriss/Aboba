1.	Для начала нужно установить требуемый пакет.

`apt install -y nfs-kernel-server` - установка пакета nfs-kernel-server.

2.	Теперь нужно создать директорию, которая будет общей.

`mkdir /raid/nfs` - создание директории nfs в /raid.

`chmod -R 777 /raid/nfs` - максимальные права на директорию.

3.	Нужно выдать доступ всей подсети, которая смотрит в сторону HQ-CLI.

`echo '/raid/nfs 192.168.200.0/28(rw,sync,no_root_squash,subtree_check)' >> /etc/exports`

`exportfs -a` - применение файла конфигурации exports.

4.	Нужно установить клиентскую часть NFS на HQ-CLI.

Важно! Данные действия нужно выполнять под root пользователем.

`apt install -y nfs-common` - установка клиентского пакета NFS.

5.	
Создание директории по условию задания.

`mkdir /mnt/nfs` - создание директории nfs в /mnt.

7.	Следующий шаг - монтирование директории.

`mount -t nfs 192.168.100.2:/raid/nfs /mnt/nfs` - монтирование директории, находя-щейся на сервере 192.168.100.2 в /raid/nfs, монтировать нужно на машину в /mnt/nfs.

7.	Заключительный шаг - настройка автомонтирования.
   
`echo '192.168.100.2:/raid/nfs /mnt/nfs nfs auto 0 0' >> /etc/fstab`
