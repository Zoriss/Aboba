В данном задании потребуется развернуть веб-приложение на сервере HQ-SRV. Необходимо подгрузить пользователей из Additional.iso в БД веб-приложения. В конце выполнения задания требуется оформить отчет.

1.	Для начала нужно установить Apache2, PHP, PHP8.2-MySQL, MariaDB-Server, MariaDB-Client.

`apt install -y apache2 php php8.2-mysql mariadb-server mariadb-client` - установка пакета Apache2, PHP и модуля PHP для MySQL, а также серверной части базы дан-ных MariaDB и клиентской части.

`systemctl enable apache2` - добавление Apache2 в автозапуск.

`systemctl enable mariadb` - добавление MariaDB в автозапуск.

`sed -i 's/^/##/' /etc/mysql/mariadb.conf.d/provider_*.cnf` - отключение модулей MariaDB.

2.	Следующий этап - настройка БД.

`mysql_secure_installation` - первоначальная настройка MariaDB. Должно появиться следующее окно, на вопросе с паролем нужно ввести P@ssw0rd, потом Y, затем на вопросе change root password ответить no, а во всех оставшихся вопросах нажать Y.

Теперь нужно подключить диск Additional.iso к ВМ

выполнить следующие команды.

`mkdir /mnt/disk` - создание директории /mnt/disk.

`mount -o loop /dev/sr1 /mnt/disk` - монтирование /dev/sr1 в /mnt/disk.

`cd /mnt/disk` - переход в директорию /mnt/disk.

Содержимое данного диска выглядит следующим образом.

4.	Следующим шагом станет создание БД. Пример выполнения команд представлен ниже.

`mysql -u root -p` - подключение к MySQL с помощью пользователя root.

`CREATE DATABASE webdb;` - создание базы данных webdb.

`CREATE USER 'web1'@'%' IDENTIFIED BY 'P@ssw0rd';` - создание пользователя web с па-ролем P@ssw0rd.

`GRANT ALL PRIVILEGES ON webdb.* TO 'web1'@'%';` - выдача всех прав на БД webdb пользователю web.

`FLUSH PRIVILEGES;` - обновление привилегий.
<img width="920" height="288" alt="image" src="https://github.com/user-attachments/assets/1fa15a17-a813-4c84-aa5a-aae317f6c5a7" />

`CTRL + D` для выхода из БД.

`systemctl restart mysql` - перезапуск базы данных MySQL.

5.	Теперь нужно наладить работу веб-сайта.

`cd web `- переход в директорию с dump.sql.

`mysql webdb < dump.sql` - подгрузка dump.sql в БД webdb.

`cp index.php /var/www/html/index.php` - перенос index.php в директорию веб-сайта Apache2 для изменения внешного вида веб-сайта на нужный.

`cp logo.png /var/www/html/` - подгрузка логотипа сайта в директорию веб-сайта Apache2.

`sed -i \`

  `-e 's/\$username = "user";/$username = "web1";/' \`

  `-e 's/\$password = "password";/$password = "P@ssw0rd";/' \`

  `-e 's/\$dbname = "db";/$dbname = "webdb";/' \`

  `/var/www/html/index.php`

Важно! Нужно index.php сделать страницей по умолчанию, чтобы не дописывать каждый раз index.php при входе на сайт, пример приведения веб-сайта к нужному виду представлен ниже.

`nano /etc/apache2/mods-enabled/dir.conf` - изменение файла конфигурации dir.conf. 

В данном файле конфигурации нужно index.php сделать первым, а index.html вторым. Пример изменения файла конфигурации представлен ниже.

`systemctl restart apache2` - перезапуск службы Apache2.
