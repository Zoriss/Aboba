В данном задании потребуется развернуть веб-приложение на сервере BR-SRV через Docker.

1.	нужно подключить диск Additional.iso к ВМ 

Выполнить следующие команды.

`mkdir /mnt/disk` - создание директории disk.

`mount -o loop /dev/sr1 /mnt/disk` - смонтировать /dev/sr1 в /mnt/disk.

`cd /mnt/disk `- перейти в раннее созданную директорию.

`curl -fsSL https://get.docker.com | sh` - запуск скрипта установки с веб-сайта docker.

5.	Следующим шагом станет подготовка директории для хранения Docker-compose.yml файла конфигурации, а также настройка Docker-compose.yml файла конфигурации.

`mkdir /opt/testapp` - создание директории testapp в /opt.

`cd /opt/testapp` - переход в директорию testapp.

Используемые переменные в Docker-compose.yml файле конфигурации для site_latest:

`DB_HOST - <IPv4 СУБД>.`

`DB_PORT - <порт TCP подключения к БД>.`

`DB_NAME - <название БД>.`

`DB_USER - <пользователь СУБД>.`

`DB_PASS - <пароль пользователя СУБД>.`

`DB_TYPE - [maria|postgres].`

Используемые переменные в Docker-compose.yml файле конфигурации для mariadb_latest:

`DB_USER - <пользователь СУБД>.`

`DB_PASS - <пароль пользователя СУБД>.`

`DB_NAME - <название БД>.`

`MARIADB_ROOT_PASSWORD - обязательные параметры.`

services:
  testapp:
    container_name: testapp
    image: site:latest
    restart: unless-stopped
    ports:
      - "8080:8000"
    environment:
      DB_HOST: "db"
      DB_PORT: "3306"
      DB_NAME: testdb
      DB_USER: test
      DB_PASS: P@ssw0rd
      DB_TYPE: maria
    depends_on:
      - db
  db:
    container_name: db
    image: mariadb:10.11
    restart: unless-stopped
    ports:
      - "3306:3306"
    environment:
      MARIADB_USER: test
      MARIADB_PASSWORD: P@ssw0rd
      MARIADB_DATABASE: testdb
      MARIADB_ROOT_PASSWORD: P@ssw0rd

6.	Следующим шагом станет создание пользователя test внутри БД, т.к. по умолчанию данного пользователя не существует.
Нужно зайти внутрь контейнера db.

`docker exec -it db bash` - вход в контейнер db, будет использоваться bash.

`mysql -u root -p `- вход в mysql под пользователем root. Пример приведен ниже.

Пароль mysql пользователя - P@ssw0rd (взят из Docker Compose файла конфигу-рации).
<img width="1003" height="294" alt="image" src="https://github.com/user-attachments/assets/5c0b52bb-c9e5-47e3-ba59-215533b387b8" />

Теперь нужно прописать следующие команды для созда-ния БД, пользователя, выдачи прав пользователю на владение базой дан-ных testdb, затем применить привилегии. Пример приведен ниже.

`CREATE DATABASE IF NOT EXISTS testdb;` - создание базы данных testdb, если ее не существует.

`CREATE USER IF NOT EXISTS 'test'@'%' IDENTIFIED BY 'P@ssw0rd';` - создание пользо-вателя test с паролем P@ssw0rd, если он не существует.

`GRANT ALL PRIVILEGES ON testdb.* TO 'test'@'%';` - выдача всех прав пользовате-лю test на базу данных testdb.

`FLUSH PRIVILEGES;` - применение привилегий.
