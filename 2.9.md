В данном задании потребуется настроить веб-сервер Nginx как обратный прокси-сервер на машине ISP.

1.	Для начала нужно перейти на машину ISP и установить Nginx, затем зайти в файл конфигу-рации Nginx.

`apt install -y nginx` - установка пакета Nginx.

2.	Затем нужно произвести настройку Reverse Proxy.
**Вариант 1**
<img width="385" height="264" alt="image" src="https://github.com/user-attachments/assets/d54bc493-57ef-4a5d-bfbb-734edaaaa038" />
```
sed -i '/^http {/,/^}/ { /^}/ i\
\
    server {\
        listen 80;\
        server_name web.au-team.irpo;\
        location / {\
            proxy_pass http://192.168.100.2:80;\
        }\
    }\
\
    server {\
        listen 80;\
        server_name docker.au-team.irpo;\
        location / {\
            proxy_pass http://192.168.0.2:8081;\
        }\
    }
}' /etc/nginx/nginx.conf
```
**Вариант 2**
Если не получается сделать то, что выше и выдает ошибку.
Самому зайти через nano в `nano /etc/nginx/nginx.conf` найти большой блок настроек, который начинается со слова `http {`. Спускайся в самый низ этого блока, прямо перед его закрывающей фигурной скобкой `}`
```
    server {
        listen 80;
        server_name web.au-team.irpo;
        location / {
            proxy_pass http://192.168.100.2:80;
        }
    }

    server {
        listen 80;
        server_name docker.au-team.irpo;
        location / {
            proxy_pass http://192.168.0.2:8081;
        }
    }
```

`systemctl restart nginx` - перезапуск службы Nginx.

2.	Следующим шагом станет проверка работы обратного прокси-сервера. Нужно зайти на машину HQ-CLI и перейти на требуемый веб-сайт по DNS имени. Примеры:` http://docker.au-team.irpo/` и `http://web.au-team.irpo/`.
