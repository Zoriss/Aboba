1.	Сперва нужно установить пакеты для создания RAID, также проверить количество дисков перед конфигурацией.

lsblk - проверка количества разделов/размеров.
<img width="771" height="386" alt="image" src="https://github.com/user-attachments/assets/d8dff918-bc87-457f-b965-e2ca2ba74c3f" />

**apt install mdadm -y** - установка пакета mdadm.
Важно! Для создания RAID будут использоваться три диска по 1GB (sdb, sdc, sdd), для начала, нужно создать разделы на данных дисках.

**fdisk /dev/sdb** - создание раздела, жмем g, а затем вводим n, нажимаем enter 3 раза, для выхода и сохранения нужно нажать w.

**fdisk /dev/sdc** - создание раздела, жмем g, а затем вводим n, нажимаем enter 3 раза, для выхода и сохранения нужно нажать w.

**fdisk /dev/sdd **- создание раздела, жмем g, а затем вводим n, нажимаем enter 3 раза, для выхода и сохранения нужно нажать w.

**lsblk** - проверка созданных разделов.
<img width="777" height="473" alt="image" src="https://github.com/user-attachments/assets/262c6894-2d2a-48b1-b454-60f4d7f0697c" />

2.	Теперь можно приступить к созданию RAID-массива.

**mdadm --create --verbose /dev/md0 -l 0 -n 3 /dev/sdb1 /dev/sdc1 /dev/sdd1** - созда-ние RAID-массива 0 уровня, который будет смонтирован в dev/md0, массив создает-ся путем объединения трех дисков /dev/sdb1, /dev/sdc1, /dev/sdd1.

3.	Теперь нужно создать раздела файловой системы ext4.

**mkfs.ext4 /dev/md0** - создание нового раздела файловой системы ext4.
<img width="931" height="402" alt="image" src="https://github.com/user-attachments/assets/be380501-9c3b-4b91-aaf9-7f6b8bad0a63" />

4.	Нужно создать директорию /raid в корне и смонтировать ее к только что созданно-му RAID-массиву.

**mkdir /raid** - создание директории /raid в корне.

**mount /dev/md0 /raid** - монтирование директории /dev/md0 в /raid.

5.	Теперь потребуется настроить автоматическое монтирование диска в директорию.

**echo '/dev/md0 /raid ext4 defaults 0 0' >> /etc/fstab**

6.	Последним шагом будет добавление RAID в автосборку при запуске системы.

**mdadm --detail --scan >> /etc/mdadm/mdadm.conf** - добавление настроек в mdadm.conf.

**update-initramfs -u** - обновление initramfs.
