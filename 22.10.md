В данном задании потребуется настроить Web-Based аутентификацию на ма-шине ISP.
1.	Для начала нужно установить Apache2-utils. Пример приведен ниже.

`apt install apache2-utils -y` - установка Apache2-utils.

2.	Далее нужно создать пароль для пользователя WEB.

`htpasswd -c /etc/nginx/.htpasswd WEB` - создание пароля для пользователя WEB с по-следующей записью в файл конфигурации .htpasswd. Пример приведен ниже.

Пароль указывается P@ssw0rd по условию задания.
<img width="634" height="139" alt="image" src="https://github.com/user-attachments/assets/59e3fb29-2f28-4b18-856b-64510d465b72" />

3.	Затем нужно обновить информацию в конфигурационном файле Nginx.

`sed -i '/server_name web\.au-team\.irpo;/i \`
    auth_basic "Restricted Access";\n    auth_basic_user_file /etc/nginx/.htpasswd;' /etc/nginx/nginx.conf

`systemctl restart nginx` - перезапуск службы nginx.

4.	Следующим шагом станет тестирование Nginx Web-Based аутентификации, нужно перейти на машину HQ-CLI и подключиться к web.au-team.irpo веб-сайту. Пример приведен ниже.
