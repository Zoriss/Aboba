В данном задании потребуется настроить ansible на сервере BR-SRV.

Теперь нужно создать ключи rsa
<img width="1018" height="444" alt="image" src="https://github.com/user-attachments/assets/f624518e-8d9c-4b82-bb23-95e669bf4ef8" />

Теперь это ключ нужно переместить на остальные машины командой:

**ssh-copy-id -p 2011 sshuser@192.168.100.2**
<img width="1018" height="371" alt="image" src="https://github.com/user-attachments/assets/70939ac2-f614-4a79-bca3-f17ac86e47ec" />

Тоже самое нужно сделать для остальных машин
Теперь нужно залогиниться обратно под root и создать директорию /etc/ansible
и зайти в файл /etc/ansible/hosts для конфигурации файла инвентаря
<img width="853" height="262" alt="image" src="https://github.com/user-attachments/assets/eb9fadfe-9155-4eda-b9c9-2ce82a7983bc" />

```/etc/ansible/hosts
[hq]
192.168.100.2 ansible_port=2024 ansible_user=sshuser
192.168.200.4 ansible_user=user
172.16.10.2 ansible_user=net_admin

[br]
172.16.20.2 ansible_user=net_admin
```

Для проверки файла инвентаря используется команда ansible all -m ping
