## HQ-SRV и BR-SRV
Сделать на HQ-SRV и на BR-SRV.

Создаем пользователя sshuser.

    useradd sshuser -u 2011 -U

создание пользователя

    passwd sshuser

задать пароль пользователю

вводим пароль пользователя - P@ssw0rd

повторяем ввод пароля - P@ssw0rd

Создаём домашнюю папку пользователя ( нужно для ansible )

    mkhomedir_helper sshuser

Заходим в `visudo` и прописываем нашего пользователя.

<img width="525" height="129" alt="image" src="https://github.com/user-attachments/assets/e8d415a3-6086-4a42-8f5d-4d0a52a7f100" />

    sshuser ALL=(ALL) NOPASSWD: ALL

## SSH ( HQ-SRV и BR-SRV )
Создадим файл баннера, допустим "banner_ssh" и напишем текст ( можно написать без =, Authorized Access Only )

    nano /etc/banner_ssh

<img width="615" height="124" alt="image" src="https://github.com/user-attachments/assets/49b1046e-5e24-4d7a-832f-13993b625343" />

    ==========================================
              Authorized Access Only
    ==========================================

Пропишем выделенные параметры в конфигурационный файл

    nano /etc/ssh/sshd_config

<img width="653" height="313" alt="image" src="https://github.com/user-attachments/assets/808a7dc3-4b4c-49ec-a784-e3268dd3d5df" />

    Port 2011
    AllowUsers sshuser
    Banner /etc/banner_ssh
    MaxAuthTries 2

После, перезапускаем службу SSH.

    systemctl restart ssh

## Проверка SSH ( HQ-RTR )

Подключаемся с HQ-RTR указав имя созданного пользователя, ip-адрес HQ-SRV и порт ( 2011 ). Далее вводим пароль.
