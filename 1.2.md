## ПРОПИСЫВАЕМ ПРАВИЛО НА ISP, HQ-RTR и BR-RTR

Добавим правило для NAT в nftables.conf

    nano /etc/nftables.conf

Указываем интерфейс, смотрящий в сторону Интернета (ens192)

<img width="553" height="386" alt="image" src="https://github.com/user-attachments/assets/611493a8-0ba5-4aec-82fb-2c538d6a4fc7" />

**ВАРИАНТ nftables ДЛЯ ПЕРВОГО МОДУЛЯ**
```
table inet nat {
    chain POSTROUTING {
    type nat hook postrouting priority srcnat;
    oifname "ens192" masquerade
    }
}
```
(Tab где нужно расставить не забываем, если не скопировалось)

**ГОТОВЫЙ ВАРИАНТ nftables ДЛЯ ВТОРОГО МОДУЛЯ 2.8**
Вариант для второго модуля

**HQ-RTR**
```
table inet nat { 
    chain PREROUTING { 
    type nat hook prerouting priority filter; 
    ip daddr 172.16.10.2 tcp dport 8081 dnat ip to 192.168.100.2:80 
    ip daddr 172.16.10.2 tcp dport 2011 dnat ip to 192.168.100.2:2011 
}

    chain POSTROUTING {
    type nat hook postrouting priority srcnat;
    oifname "ens192" masquerade
    }
}
```
**BR-RTR**
```
table inet nat {
    chain PREROUTING {
    type nat hook prerouting priority filter;
    ip daddr 172.16.20.2 tcp dport 8081 dnat ip to 192.168.0.2:8081
    ip daddr 172.16.20.2 tcp dport 2011 dnat ip to 192.168.0.2:2011
}
    chain POSTROUTING {
    type nat hook postrouting priority srcnat;
    oifname "ens192" masquerade
    }
}
```




    systemctl enable nftables
добавление службы в автозапуск

    systemctl start nftables
включение службы

Не забываем про переадресацию пакетов `nano /etc/sysctl.conf`
